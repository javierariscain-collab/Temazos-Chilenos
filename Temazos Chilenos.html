Writing, Done, Verify

Built index.html — single-file PWA, drop-in for GitHub Pages. Empty state shows when no ?v= is present; player UI runs the YouTube IFrame API completely hidden offscreen and exposes only your DJ controls.

1. Deploy on GitHub Pages

  1. Sign in at github.com → click + (top right) → New repository.
  2. Name it hitster-chile → set Public → check Add a README → Create repository.
  3. In the new repo: click Add file → Upload files → drag index.html in → Commit changes.
  4. Go to Settings → Pages (left sidebar).
  5. Under Build and deployment → Source, pick Deploy from a branch.
  6. Branch: main, folder: / (root) → Save.
  7. Wait ~1 min, refresh the Pages screen. You'll see: Your site is live at https://<your-username>.github.io/hitster-chile/

To update later: edit index.html in the GitHub web UI (pencil icon) → commit. Pages redeploys in ~30 s.

2. Test locally before deploying

The app needs a real HTTP server (YouTube's iframe API won't run from file://). Pick one:

Easiest — VS Code: install the Live Server extension → right-click index.html → Open with Live Server.

Python (already installed on Mac):

cd /folder/with/index.html
python3 -m http.server 8000

Open http://localhost:8000/?v=dQw4w9WgXcQ in Safari/Chrome.

iPhone on same Wi-Fi: find your Mac's IP (System Settings → Wi-Fi → Details), then on iPhone visit http://<mac-ip>:8000/?v=dQw4w9WgXcQ. Note: iOS audio session + add-to-home-screen behave fully correctly only over HTTPS — for those, test the live GitHub Pages URL.

3. QR code URL format

Each card's QR encodes:

https://<your-username>.github.io/hitster-chile/?v=VIDEO_ID

Where VIDEO_ID is the 11-character ID from any YouTube URL:

  • https://www.youtube.com/watch?v=dQw4w9WgXcQ → use dQw4w9WgXcQ
  • https://youtu.be/dQw4w9WgXcQ → same
  • https://www.youtube.com/shorts/dQw4w9WgXcQ → same

Example final URL:

https://juanperez.github.io/hitster-chile/?v=dQw4w9WgXcQ

The app is tolerant — if you accidentally encode a full YouTube URL into the ?v= param it will still extract the ID.

4. Add to iPhone home screen (PWA install)

  1. Open the GitHub Pages URL in Safari (must be Safari, not Chrome).
  2. Tap the Share icon (square with up arrow) at the bottom.
  3. Scroll down → Add to Home Screen.
  4. Name stays "Hitster Chile" → Add.
  5. Launch from the home-screen icon — opens full-screen, no Safari chrome, status bar matches the dark theme.

The PWA still reads ?v= correctly when launched via a QR scan from Camera (it'll just open Safari with the URL); for the cleanest experience, leave a Safari tab open and scan QRs into it.

Notes / caveats

  • iOS requires a user tap to start audio — handled: the INICIAR button is your unlock gesture. After that, pause/resume work freely.
  • The volume slider controls YouTube's player volume; on iOS the physical side buttons still work too.
  • Error code 101/150 from YouTube → "Video no disponible, escanea de nuevo". Code 100 → "Video no encontrado". Anything else → generic "No se pudo cargar" with retry.
